How to Calculate a Percentage

To calculate a percentage of a number, multiply the number by the percentage and divide the result by 100.

Result = Number × Percentage ÷ 100

Example:

15% of 1,500
1,500 × 15 ÷ 100 = 225

How to Find What Percentage One Number Is of Another

Divide the first value by the second value and multiply by 100.

Percentage = First Number ÷ Second Number × 100

Example:

200 is what percent of 800?
200 ÷ 800 × 100 = 25%

How to Calculate a Percentage Increase

To increase a number by a percentage, first calculate the percentage amount and add it to the original value.

New Value = Original Value × (1 + Percentage ÷ 100)

Example:

Increase 1,000 by 20%
1,000 × 1.20 = 1,200

How to Calculate a Percentage Decrease

To decrease a number by a percentage, subtract the percentage amount from the original value.

New Value = Original Value × (1 − Percentage ÷ 100)

Example:

Decrease 1,000 by 20%
1,000 × 0.80 = 800

How to Calculate Percentage Change

Percentage change compares an old value with a new value.

Percentage Change = (New Value − Old Value) ÷ Old Value × 100

Example:

Old value: 800
New value: 1,000

(1,000 − 800) ÷ 800 × 100 = 25% increase

Frequently Asked Questions

How do you calculate 20% of a number?

Multiply the number by 20 and divide by 100. For example, 20% of 500 is 100.

How do I calculate what percentage one number is of another?

Divide the first number by the second number and multiply the result by 100.

How do I add 15% to a number?

Multiply the number by 1.15. For example, 1,000 increased by 15% becomes 1,150.

How do I subtract 20% from a number?

Multiply the number by 0.80. For example, 1,000 reduced by 20% becomes 800.

Is percentage increase the same as percentage change?

Percentage increase is a type of percentage change where the new value is greater than the old value. Percentage change can describe either an increase or a decrease.
